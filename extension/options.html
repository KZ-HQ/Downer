Leave blank to let FFmpeg choose. This affects processing, not parallel HLS segment requests.

Downloads whose media URL says nothing useful are named video.mp4, so repeats are common and "Keep both" is the default. "Replace the existing file" permanently discards what is already there.

Off by default. When on, a download whose media URL has no useful filename is named after the page's title instead of video.mp4. Page titles can contain account or document names, which would then appear in your Downloads folder.
