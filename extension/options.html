Downer settings

Blank uses your desktop's download folder, or ~/Downloads where it has none. Check setup below names the exact directory, and creates it on the first download if it isn't there yet.

Firefox starts the native host with a minimal environment, so it cannot see a PATH you set in a shell. Give a full path here if your FFmpeg is somewhere unusual.

Leave blank to let FFmpeg choose. This affects processing, not parallel HLS segment requests.

Downloads whose media URL says nothing useful are named video.mp4, so repeats are common and "Keep both" is the default. "Replace the existing file" permanently discards what is already there.

Off by default. When on, a download whose media URL has no useful filename is named after the page's title instead of video.mp4. Page titles can contain account or document names, which would then appear in your Downloads folder.

Off by default: cancelling deletes what was written so far, because a cancel means you did not want the file. Turn this on to keep the fragment — it will not play, but it is evidence for why a download went wrong. A download that fails on its own always keeps its part-written file, whichever way this is set.

Setup
